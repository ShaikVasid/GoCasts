# GoCasts

A collection of Go examples and exercises from my early work learning the language.

I kept this repository as a reference while getting comfortable with Go syntax, packages, functions, interfaces, error handling, and small scripting-style programs.

## Why it is here

Most of my day-to-day automation work is around cloud infrastructure and DevOps. Go is useful in that space, especially for building small command-line tools and infrastructure utilities, so I keep these examples around as a learning reference.

## What you'll find

- Basic Go programs
- Functions and packages
- Structs and interfaces
- Error handling
- Small automation examples
- Exercises from the learning material I used

This is a learning repository rather than a polished production project. My larger portfolio projects are the Azure Terraform and Azure RBAC repositories on my profile.
